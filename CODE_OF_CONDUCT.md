# Code of Conduct

Be respectful and constructive. Harassment, discrimination, and personal attacks are
not acceptable.

This project is a technical reference implementation. Contributions should focus on
verifiable behavior, clear documentation, and honest limitations—not hype or
unsupported production claims.

Maintainers may decline or revert contributions that introduce secrets, weaken
tenant isolation, or hide failing tests with skips, xfails, or arbitrary sleeps.
